              Sharing into Wayfinder

              Android

              Install the app (browser menu → Install app / Add to Home screen). Wayfinder then appears in the share sheet of TikTok, Instagram, YouTube, Google Maps, Gallery and so on.

              iPhone / iPad

              Safari doesn’t let web apps join the share sheet, so use a one-time Shortcut:

              1. Shortcuts → + → name it “Wayfinder”, turn on Show in Share Sheet, accept URLs and Text.
              2. Add URL Encode (input: Shortcut Input).
              3. Add Open URLs with [URL Encoded Text].

              Then Share → Wayfinder from any app. For videos saved to Photos, use the 🎬 button instead.

              Desktop

              Drag this to your bookmarks bar, then click it on any page: + Wayfinder
